⏱ 빅오(Big-O) 표기법

정렬과 탐색으로 이해하는 알고리즘 효율

빅오는 정확한 시간보다, 입력이 커질 때 알고리즘이 얼마나 빠르게 느려지는지를 비교하는 방법이에요.

빅오를 한마디로 말하면?

빅오 표기법은 입력 데이터의 개수 n이 커질 때, 알고리즘의 작업량이 어떻게 늘어나는지 나타내요. 예를 들어 숫자 5개를 처리할 때는 괜찮았는데 1,000개가 되면 얼마나 더 오래 걸릴지 비교하는 기준입니다.

일상 비유: 책에서 이름 찾기

책의 첫 페이지부터 한 장씩 찾으면 책이 2배 두꺼워질 때 찾는 일도 대략 2배 늘어납니다. 이것은 O(n)이에요.

반대로 책을 반씩 나누며 찾으면 페이지가 훨씬 많아져도 찾는 횟수는 조금만 늘어납니다. 이것은 O(log n)과 연결돼요.

자주 만나는 네 가지

O(1) 거의 일정한 작업

O(n) 하나씩 확인하는 작업

O(n log n) 나누면서 전체를 한 번씩 살피는 작업

O(n²) 여러 번 반복해서 비교하는 작업

정렬 알고리즘으로 빅오 이해하기

정렬 탭에서 본 세 알고리즘은 같은 숫자를 정렬하지만, 비교하는 방식이 달라요.

버블 정렬 — 이웃한 값들을 반복해서 비교·교환
O(n²) 숫자가 많아지면 비교가 빠르게 늘어납니다.
선택 정렬 — 매번 남은 숫자에서 최솟값을 찾음
O(n²) 앞자리를 정해도 계속 남은 값을 살펴봐야 합니다.
퀵 정렬 — 피벗으로 작은 그룹과 큰 그룹을 나눔
평균 O(n log n) 균형 있게 나뉘면 빠릅니다.
핵심 생각
버블·선택 정렬은 여러 번 전체를 살피는 느낌이라 O(n²)이고, 퀵 정렬은 그룹을 나누어 한 번에 살피는 범위를 줄이기 때문에 평균적으로 O(n log n)입니다.

퀵 정렬의 피벗이 계속 최솟값이나 최댓값이면 그룹이 균형 있게 나뉘지 않아 최악의 경우 O(n²)이 될 수 있어요.

탐색 알고리즘으로 빅오 이해하기

탐색 탭에서 볼 수 있는 선형 탐색과 이진 탐색은 빅오 차이를 보여 주는 좋은 예입니다.

선형 탐색 — 맨 앞부터 하나씩 확인
O(n) 최악의 경우 마지막 값까지 모두 확인합니다.
이진 탐색 — 가운데 값과 비교하고 절반을 버림
O(log n) 단, 배열이 정렬되어 있어야 합니다.

→
50개1번
→
25개2번
→
1개약 7번

선형 탐색은 후보를 하나씩 줄이고, 이진 탐색은 후보를 절반씩 줄입니다. 그래서 입력이 커질수록 두 방법의 차이가 커져요.

🔢 로그(log)가 뭔지 몰라도 괜찮아요

로그는 “몇 번 반으로 나누면 1이 되는가?”를 세는 생각이에요.

숫자 맞히기 게임

1부터 100 사이의 숫자를 맞힌다고 해 봅시다. 매번 가운데 숫자를 물으면 후보가 절반씩 줄어들어요.
100개처음
→
50개1번
→
25개2번
→
12개3번
→
1개약 7번

log₂100 ≈ 6.6이므로 약 7번이면 됩니다. 후보가 100개에서 100만 개로 커져도 필요한 질문은 약 7번에서 20번 정도로만 늘어나요.

정렬·탐색과 연결하기

이진 탐색은 매번 탐색 범위를 절반으로 줄이므로 O(log n)입니다. 퀵 정렬도 피벗으로 그룹을 균형 있게 나누면 비슷한 “절반씩 줄이기” 효과가 생겨 평균 O(n log n)이 됩니다.

그래프는 정확한 초 단위 시간이 아니라, 입력 크기가 커질 때 작업량이 증가하는 경향을 보여 줍니다.

서술형 4문제

답을 직접 작성한 뒤 서술형 예시 답안 확인 버튼을 누르세요. 자신의 답과 비교해 보세요.

1. 버블 정렬과 퀵 정렬의 평균 시간 복잡도를 비교하고, 숫자가 많을 때 퀵 정렬이 유리한 이유를 설명해 보세요.
예시 답안 보기

버블 정렬은 평균 O(n²), 퀵 정렬은 평균 O(n log n)이다. n이 커질수록 O(n²)이 O(n log n)보다 훨씬 빠르게 증가하므로 퀵 정렬이 유리하다.

2. 선형 탐색과 이진 탐색의 차이를 ‘후보를 줄이는 방법’으로 설명해 보세요.
예시 답안 보기

선형 탐색은 처음부터 하나씩 확인해 후보를 한 개씩 줄인다. 이진 탐색은 가운데 값과 비교해 절반을 버리므로 후보를 절반씩 줄인다.

3. 로그(log)를 숫자 맞히기 게임과 연결하여 설명해 보세요.
예시 답안 보기

로그는 어떤 수를 몇 번 반으로 나누어야 1이 되는지를 나타내는 생각이다. 1~100 숫자 맞히기에서 매번 가운데를 물으면 후보가 절반씩 줄어 약 7번 만에 좁힐 수 있다.

4. 퀵 정렬에서 피벗을 잘못 고르면 최악의 경우 O(n²)이 될 수 있는 이유를 설명해 보세요.
예시 답안 보기

피벗이 계속 최솟값이나 최댓값이면 그룹이 한쪽으로만 치우친다. 매번 절반씩 나누지 못하고 한 개씩만 줄어들어 비교가 반복되므로 O(n²)이 된다.
