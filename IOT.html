마이크로비트 온도계 (교과서 30~33p)

실외 마이크로비트가 온도를 라디오로 전송하고, 실내 마이크로비트가 받아서 비교합니다. 온도 차가 5도 이하면 하트, 넘으면 체스판이 나타납니다.

실외 마이크로비트

온도를 재서 보낸다 (송신)
5 ℃
실제 프로그램에서는 무한 반복 안에서 30초마다 자동으로 전송합니다. 전송 간격이 길수록 전지를 오래 씁니다.

실내 마이크로비트

받아서 판단하고 보여 준다 (수신)
24 ℃
대기 중
확인해 보기 · 두 마이크로비트의 라디오 그룹을 다르게 하면 어떻게 될까요? 같은 그룹에서만 데이터를 주고받을 수 있습니다. (교과서 32~33p)
☐ 하트가 나오게 만들어 보자. (온도 차 5도 이하)
☐ 체스판이 나오게 만들어 보자. (온도 차 5도 초과)
☐ 그룹을 다르게 해서 수신이 안 되는 것을 확인해 보자.

이 실습의 의사 코드

실외 : 라디오 그룹 설정 → 무한 반복 { 온도 전송, 30초 기다림 } 실내 : 라디오 그룹 설정 → 숫자 수신 시 { 'In' 출력, 실내 온도, 'Out' 출력, 실외 온도, 만약 |실내−실외| ≤ 5 이면 하트, 아니라면 체스판 }
실제 마이크로비트의 온도 센서는 프로세서에 있어 실제 공기 온도보다 조금 높게 측정됩니다.
