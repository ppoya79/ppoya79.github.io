데이터가 그림이 되는 곳

오렌지3는 위젯을 선으로 연결해 데이터를 분석하는 오픈소스 도구입니다. 프로그래밍을 몰라도 산점도·상자 그림·히스토그램을 자유롭게 그리고, 그림 위에서 마우스로 데이터를 직접 골라낼 수 있습니다.

오렌지3란

스프레드시트를 다루듯, 데이터 분석을 다룹니다

슬로베니아 류블랴나 대학이 만드는 오픈소스 데이터 마이닝 도구. 분석 절차를 ‘코드’가 아니라 ‘그림(워크플로우)’로 만듭니다.

오렌지3에서 분석은 위젯을 연결하는 일입니다. 데이터를 불러오는 File, 관계를 보는 Scatter Plot, 결과를 확인하는 Data Table — 기능 블록을 캔버스에 놓고 선으로 잇으면, 그 연결도가 곧 분석 절차가 됩니다.

시각화 위젯은 ‘보여 주기’로 끝나지 않습니다. 그래프 위에서 점을 직접 드래그해 선택하면 그 선택이 하나의 데이터 필터가 되어 다음 위젯으로 전달됩니다. 그림을 보는 행위가 곧 분석이 되는 셈입니다.

그래서 오렌지3는 초·중·고·대학의 데이터 문해 수업에서 널리 쓰입니다. 개념 설명에 코드가 필요 없고, 결과가 즉시 눈에 보이기 때문입니다.

시작하기

설치부터 수업 활용까지

설치는 5분, 첫 산점도는 그 다음 5분이면 충분합니다.

  1. 설치 프로그램 내려받기

    공식 사이트 orange.biolab.si에서 Windows·macOS·Linux용 설치 프로그램을 받거나, Python 환경이라면 pip install orange3으로 설치합니다.

  2. 캔버스 열기

    실행하면 곧바로 캔버스가 열립니다. 화면 왼쪽 도구 상자가 위젯 목록 — 원하는 위젯을 끌어다 놓으면 됩니다.

  3. iris 열고 산점도 그리기

    File 위젯을 놓고 더블클릭 → 데이터셋 목록에서 iris 선택 → Scatter Plot을 연결합니다. X축·Y축·색을 바꿔 가며 보세요.

수업 팁 ① 도입 10분 — 질문 한 개

“타이타닉에서 누가 살아남았을까?” titanic 데이터를 Mosaic Display와 Tree Viewer로 열고, 답을 데이터에서 찾게 합니다.

수업 팁 ② 실습 한 판 — 우리 데이터

모둠 설문·체육 기록·독서량 등을 CSV로 만들어 File에 넣고 산점도로 그리게 합니다. 내 데이터가 그림이 되는 경험이 핵심입니다.

수업 팁 ③ 심화 — 그림에서 모델로

산점도에서 고른 점을 Tree로 보내 학습하고, Test & Score로 정확도를 확인합니다. 시각화가 분석의 출발점이 됩니다.
