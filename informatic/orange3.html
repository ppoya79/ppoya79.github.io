데이터가 그림이 되는 곳

오렌지3는 위젯을 선으로 연결해 데이터를 분석하는 오픈소스 도구입니다. 프로그래밍을 몰라도 산점도·상자 그림·히스토그램을 자유롭게 그리고, 그림 위에서 마우스로 데이터를 직접 골라낼 수 있습니다.

오렌지3란

스프레드시트를 다루듯, 데이터 분석을 다룹니다

슬로베니아 류블랴나 대학이 만드는 오픈소스 데이터 마이닝 도구. 분석 절차를 ‘코드’가 아니라 ‘그림(워크플로우)’로 만듭니다.

오렌지3에서 분석은 위젯을 연결하는 일입니다. 데이터를 불러오는 File, 관계를 보는 Scatter Plot, 결과를 확인하는 Data Table — 기능 블록을 캔버스에 놓고 선으로 잇으면, 그 연결도가 곧 분석 절차가 됩니다.

시각화 위젯은 ‘보여 주기’로 끝나지 않습니다. 그래프 위에서 점을 직접 드래그해 선택하면 그 선택이 하나의 데이터 필터가 되어 다음 위젯으로 전달됩니다. 그림을 보는 행위가 곧 분석이 되는 셈입니다.

그래서 오렌지3는 초·중·고·대학의 데이터 문해 수업에서 널리 쓰입니다. 개념 설명에 코드가 필요 없고, 결과가 즉시 눈에 보이기 때문입니다.

시각화 위젯 갤러리

어떤 그림을 그릴 수 있나

Visualize 범주의 대표 위젯 여덟 가지. 모두 그래프 위에서 직접 데이터를 선택해 다음 단계로 넘길 수 있습니다.

산점도Scatter Plot
두 변수를 X·Y축에 놓고 한 행을 점 하나로. 색·크기·모양으로 변수를 더 겹쳐 표현합니다.
언제: 두 변수의 관계, 집단이 갈라지는 지점을 볼 때
상자 그림Box Plot
중앙값·사분위수·이상치를 한 줄로 요약해, 집단별 분포를 나란히 비교합니다.
언제: 집단 간 값의 퍼짐과 이상치를 비교할 때
분포Distributions
히스토그램과 밀도 곡선으로 한 변수의 모양을 봅니다. 색으로 집단별 분포를 겹쳐 비교할 수 있습니다.
언제: 한 변수가 어떻게 퍼져 있는지, 집단별로 다른지 볼 때
선 그래프Line Plot
행 순서나 시간의 흐름에 따른 변화를 선으로 이어 보입니다.
언제: 시계열·누적 데이터의 추세와 변곡점을 볼 때
열 지도Heat Map
값의 크기를 색의 진하기로 바꿔 표 전체를 한눈에. 행·열을 재정렬해 패턴을 드러냅니다.
언제: 변수가 많을 때 덩어리·패턴을 찾을 때
모자이크Mosaic Display
범주형 변수 여러 개의 조합 비율을 사각 면적으로 쌓아 보여 줍니다.
언제: 생존이 객실 등급·성별에 따라 달라졌는지처럼 범주 조합을 볼 때
트리 뷰어Tree Viewer
학습된 의사결정나무를 분기 구조 그대로 그립니다. 어떤 변수가 먼저 갈랐는지 읽을 수 있습니다.
언제: 모델의 판단 근거를 사람에게 설명할 때
바이올린Violin Plot
상자 그림에 분포의 모양을 입힌 그림. 값이 어디에 몰려 있는지까지 보입니다.
언제: 퍼짐뿐 아니라 분포의 ‘모양’까지 비교할 때

시작하기

설치부터 수업 활용까지

설치는 5분, 첫 산점도는 그 다음 5분이면 충분합니다.

  1. 설치 프로그램 내려받기

    공식 사이트 orange.biolab.si에서 Windows·macOS·Linux용 설치 프로그램을 받거나, Python 환경이라면 pip install orange3으로 설치합니다.

  2. 캔버스 열기

    실행하면 곧바로 캔버스가 열립니다. 화면 왼쪽 도구 상자가 위젯 목록 — 원하는 위젯을 끌어다 놓으면 됩니다.

  3. iris 열고 산점도 그리기

    File 위젯을 놓고 더블클릭 → 데이터셋 목록에서 iris 선택 → Scatter Plot을 연결합니다. X축·Y축·색을 바꿔 가며 보세요.
