자동 설정 vs 수동 설정

DHCP 서비스가 제공되면 → 컴퓨팅 시스템이 IP 주소·서브넷 마스크·게이트웨이·DNS를 자동으로 할당받는다. 별도 설정이 필요 없다.
DHCP가 지원되지 않으면 → 네트워크 관리자에게 문의하여 네 가지 정보를 직접 입력(수동 설정)해야 한다.

비유로 이해하기

IP 주소 = 집 주소
인터넷상에서 나를 찾아오게 하는 번호
서브넷 마스크 = 우편번호
내 주소가 어느 동네(네트워크)인지 구분
게이트웨이 = 동네 정문
바깥 네트워크로 나가는 출입구
DNS = 전화번호부
www.korea.kr → 숫자 주소로 바꿔 줌

유선 네트워크 설정하기

[네트워크] 아이콘 → [네트워크 및 인터넷] → [이더넷] → IP 설정 편집 화면이다. 관리자의 요청서를 읽고 인터넷 프로토콜 버전 4(TCP/IPv4) 속성 창을 알맞게 설정한 뒤 [확인]을 누르자.

인터넷 프로토콜 버전 4(TCP/IPv4) 속성✕
일반
네트워크가 IP 자동 설정 기능을 지원하면 IP 설정이 자동으로 할당되도록 할 수 있습니다. 지원하지 않으면, 네트워크 관리자에게 적절한 IP 설정값을 문의해야 합니다.
기억하기 · 자동으로 받기를 선택하면 입력 칸은 비활성화(회색)된다. 수동으로 설정할 때는 네 칸 모두 0~255 사이 숫자여야 하고, IP 주소와 게이트웨이는 같은 네트워크에 있어야 한다.

진행 순서

  1. 스마트폰 → [설정] → [Wi-Fi]를 누른다.
  2. 비활성화되어 있는 Wi-Fi 버튼을 켠다.
  3. 연결 가능한 Wi-Fi 중 class 1을 선택한다.
  4. Wi-Fi 암호를 입력한 후 [연결]을 누른다.
